TreeDiagrams

This is a minimal library for visualizing trees as SVG.

It provides two kinds of tree visualization

  1. "normal" tree diagrams - `data Tree a = Node a [Tree a]` - `data SymbolTree nt t = TLeaf t | NTNode nt [SymbolTree nt t]`

  1. "proof tree" - `data ProofTree r a = Axiom a | ProofTree a r [ProofTree r a]`

Please see the README on GitHub at https://github.com/ren-zeng/TreeDiagrams#readme
